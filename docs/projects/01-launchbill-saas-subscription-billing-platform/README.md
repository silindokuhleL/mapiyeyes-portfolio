# LaunchBill SaaS Subscription Billing Platform

LaunchBill is the first flagship portfolio project. It should prove that Silindokuhle can build a production-minded SaaS platform with a Laravel REST API, a Next.js frontend, authentication, RBAC, subscriptions, payment webhooks, dashboards, queues, and deployment documentation.

## Why This Project Comes First

This project gives the strongest proof for the public profile title: Full-Stack SaaS Engineer.

It demonstrates:

- SaaS product architecture.
- REST API design.
- Laravel backend depth.
- Next.js frontend delivery.
- RBAC and protected workflows.
- Payments and subscription lifecycle handling.
- Queue jobs and notification workflows.
- Dashboard and reporting UI.
- Testing and deployment discipline.

## Product Idea

LaunchBill lets a small SaaS business manage subscription plans, customers, invoices, payments, and account access from a clean admin dashboard.

## Core Roles

- Platform Admin: manages plans, users, customers, invoices, and system settings.
- Account Owner: manages their company subscription and billing details.
- Team Member: views allowed dashboard data based on role.

## Suggested Stack

- Backend: Laravel REST API.
- Frontend: Next.js with TypeScript.
- Database: MySQL or PostgreSQL.
- Cache and queues: Redis.
- Payments: PayFast first, with Stripe as a possible global provider later.
- Auth: Laravel Sanctum or token-based API auth.
- Deployment: Backend on a Laravel-friendly host, frontend on Vercel.
