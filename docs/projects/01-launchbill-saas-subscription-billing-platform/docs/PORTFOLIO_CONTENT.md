# LaunchBill Portfolio Content

## Portfolio Card Title

LaunchBill SaaS Billing Platform

## Short Summary

A full-stack subscription billing platform built with Laravel and Next.js, covering REST APIs, RBAC, PayFast payments, invoices, webhooks, queues, dashboards, and deployment documentation.

## Feature Bullets

- Subscription plans and customer billing records.
- PayFast webhook handling for payment and subscription state.
- Role-based access for owners, billing managers, and viewers.
- Dashboard metrics for revenue, invoices, failed payments, and active subscriptions.
- Queue-backed notification and billing workflows.

## Stack

- Laravel
- Next.js
- TypeScript
- MySQL or PostgreSQL
- Redis
- PayFast
- Docker
- Vercel
