# AI Document Intelligence

Status: parked until LaunchBill is complete.

## Purpose

Build an AI-assisted document portal that can upload documents, extract text, search content, summarize files, and answer questions against document content.

## Why It Fits The Profile

This project upgrades the existing document-search proof into a stronger AI workflow project while still proving backend architecture, parsing, storage, search, and access control.

## Core Features

- PDF upload.
- Text extraction.
- Search.
- AI summary.
- Ask a question against documents.
- Document categories.
- Role-based access.
- Audit log.
