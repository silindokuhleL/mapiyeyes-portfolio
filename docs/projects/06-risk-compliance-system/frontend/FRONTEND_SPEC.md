# Risk Compliance System Frontend Spec

## Goal

Create a business-focused risk dashboard with clear registers, scoring, mitigation tracking, approvals, and reports.

## Pages

- Risk dashboard.
- Risk register.
- Risk detail.
- Mitigation tasks.
- Approval queue.
- Reports.
- Settings.

## UI Priorities

- Business-friendly language.
- Clear severity indicators.
- Filters by department, owner, severity, and status.
- Report-ready layouts.
- Mobile-friendly risk cards.
