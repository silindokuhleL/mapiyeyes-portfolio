# Booking Payments Marketplace Frontend Spec

## Goal

Create a marketplace interface where customers can discover services, book appointments, and complete payment while providers manage availability and bookings.

## Pages

- Marketplace home.
- Provider profile.
- Service detail.
- Booking checkout.
- Customer bookings.
- Provider dashboard.
- Admin dashboard.

## UI Priorities

- Clear service cards.
- Simple booking steps.
- Strong payment feedback.
- Provider/admin dashboards that feel operational, not decorative.
- Mobile-first booking flow.
