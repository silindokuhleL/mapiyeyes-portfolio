# Booking Payments Marketplace

Status: parked until LaunchBill is complete.

## Purpose

Build a marketplace where service providers can publish services, customers can book appointments, and payments can be tracked through provider and admin dashboards.

## Why It Fits The Profile

This project is easy for clients to understand and shows product workflows, marketplace logic, bookings, payments, and operational dashboards.

## Core Features

- Provider onboarding.
- Services.
- Availability.
- Customer bookings.
- Payments.
- Reviews.
- Provider dashboard.
- Admin approval workflow.
