# Multitenant Helpdesk

Status: parked until LaunchBill is complete.

## Purpose

Build a support ticket SaaS that proves tenant isolation, customer support workflows, agent assignment, internal notes, SLA tracking, and dashboard reporting.

## Why It Fits The Profile

This project proves SaaS workflow design beyond billing. It shows that the same Laravel and Next.js skills can support multi-tenant operational tools used by real businesses.

## Core Features

- Organizations or tenants.
- Customers and support agents.
- Tickets with status, priority, and category.
- Ticket comments.
- Internal notes.
- Agent assignment.
- SLA timers.
- Dashboard reporting.
