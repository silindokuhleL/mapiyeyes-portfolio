# Multitenant Helpdesk Frontend Spec

## Goal

Create a clean support dashboard for agents and a simple customer portal for ticket updates.

## Pages

- Login.
- Agent dashboard.
- Tickets list.
- Ticket detail.
- New ticket.
- Customer portal.
- Settings.

## UI Priorities

- Fast scanning.
- Clear status badges.
- Strong filters.
- Timeline-style ticket conversations.
- Mobile-friendly ticket detail view.
